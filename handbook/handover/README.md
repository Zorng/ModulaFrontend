# Handover (Frontend)

This folder is the single place to onboard a new teammate or AI agent to the frontend repo.

Recommended reading order:
1) **Quickstart**
   - `handbook/handover/runbook.md` (how to run/debug)
   - `handbook/handover/toolchain.md` (pinning Flutter/Dart + deps)
   - `handbook/handover/demo_accounts.md` (demo credentials + tenant/branch IDs)

2) **Product + navigation context**
   - `handbook/architecture/overview.md`
   - `handbook/architecture/navigation.md`
   - `docs/responsive_breakpoints.md`

3) **Working rules (team contract)**
   - `handbook/non_negotiables.md`
   - `handbook/architecture/widgets.md` (reuse + debloat rules)
   - `handbook/quality/error_handling.md`

4) **Quality gate**
   - `handbook/quality/testing.md`
   - `handbook/handover/pr_checklist.md`

5) **Operations + accountability**
   - `handbook/handover/ownership.md`
   - `handbook/handover/release_checklist.md`
   - `handbook/handover/known_issues.md`

Tip: For a new contributor, the minimal path is steps **1 → 2 → 3 → 4**.
