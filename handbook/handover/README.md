- `handbook/handover/toolchain.md` (pinning Flutter/Dart + deps)
- `handbook/handover/demo_accounts.md` (demo credentials + tenant/branch IDs)
- `handbook/handover/ownership.md` (who owns what)
- `handbook/handover/pr_checklist.md` (what must be true before merge)
- `handbook/handover/release_checklist.md` (demo/release smoke checklist)
- `handbook/handover/known_issues.md` (recurring issues + workarounds)
